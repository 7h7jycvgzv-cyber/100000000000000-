STEP 1

アセスメントで見る観点

術後早期は「合併症が起きていないか」「起きる前に防げているか」が中心。項目ごとに、何を見て、なぜ見るのかを確かめる。

呼吸
  • 呼吸数、SpO2、呼吸音(左右差、副雑音)、痰の量と性状、咳ができるか
  • なぜ:全身麻酔と腹部の創の痛みで深呼吸や咳がしにくく、無気肺や肺炎が起きやすい

問い:受け持ちの方の喫煙歴や呼吸器の既往は?痛みで呼吸が浅くなっていないか?

循環・出血
  • 血圧、脈拍、尿量、ドレーン排液の量と色の変化、創部の出血、血液データ(Hb)
  • なぜ:術後早期(特に24〜48時間)は後出血が起きうる。排液が急に血性に濃くなる、量が増える、頻脈や血圧低下は要注意

問い:排液の色は時間とともにどう変わっている?尿量は保たれている?

疼痛
  • 痛みの強さ(NRSなど)、部位、鎮痛薬の種類と使った時間、表情、体動時の痛み
  • なぜ:痛みは呼吸、離床、睡眠のすべてに影響する

問い:痛みのせいで、できていないこと(深呼吸、離床、睡眠)はある?

創部・感染・縫合不全
  • 創部の発赤・腫脹・熱感・滲出液、体温、ドレーン排液の混濁や性状の変化、血液データ(WBC、CRP)
  • なぜ:吻合部の縫合不全は術後数日たってから起きることがある。排液の性状の変化と発熱・腹痛は重要なサイン

問い:今日は術後何日目?その日に起きやすい合併症は何?

消化・腸の動き
  • 腸蠕動音、排ガス・排便、腹部膨満、悪心・嘔吐
  • なぜ:手術で腸の動きが一時的に止まる。回復が遅れるとイレウスにつながる

問い:排ガスはいつあった?離床と腸の動きの関係は?

活動・離床・血栓
  • 離床の進み具合、ふらつき、下肢の腫れや痛み、弾性ストッキングなどの予防の実施
  • なぜ:臥床が続くと深部静脈血栓症や筋力低下が起きやすい。初めての離床時の肺塞栓にも注意

問い:離床を妨げているもの(痛み、ルート類、不安)は何?

意識・精神
  • 見当識、夜間の睡眠、落ち着きのなさ、ルート類を気にする様子
  • なぜ:高齢の方は術後せん妄が起きやすい。転倒やルートの自己抜去につながる

問い:手術前と比べて、話し方や反応に変化はある?

退院後の生活(食事)
  • 食事が始まったあとの摂取量、食後の症状、体重、本人と家族の理解
  • なぜ:胃を切除すると、一度に食べられる量が減り、ダンピング症候群が起きることがある。退院後の食べ方が生活の中心の課題になる

問い:家で食事を作るのは誰?本人は何を不安に思っている?

STEP 2

関連図の骨組み

中心から「原因 → 起きること → 看護問題」の順につなぐ。受け持ちの方に当てはまる線だけ残し、当てはまらない線は消す。

胃がん → 幽門側胃切除術(全身麻酔・手術侵襲)
全身麻酔・創の痛み → 深呼吸と咳がしにくい → 痰がたまる
→ 無気肺・肺炎のリスク
手術侵襲 → 止血が不十分
→ 術後出血のリスク
創・ドレーン・吻合部
→ 感染・縫合不全のリスク
腸管の操作・麻酔の影響 → 腸の動きが低下
→ イレウスのリスク
臥床・手術 → 血流が滞る
→ 深部静脈血栓症のリスク
創の痛み → 離床・睡眠の妨げ
→ 急性疼痛
高齢・環境の変化・痛み・睡眠不足
→ 術後せん妄のリスク
胃の切除 → 食べられる量の減少・ダンピング症候群
→ 栄養状態の低下・退院後の生活への不安

問い:既往歴、年齢、生活背景で、受け持ちの方だけに追加すべき線はある?

STEP 3

優先度の考え方

「命に関わる → 合併症を防ぐ → 苦痛をとる → 生活に戻る」の順で並べる。ただし、同じ問題でも、その日の状態で順位は変わる。

  1. 命に関わる呼吸(無気肺・肺炎)、出血。悪化すると短時間で生命に影響する
  2. 合併症を防ぐ感染・縫合不全、イレウス、深部静脈血栓症、せん妄
  3. 苦痛疼痛。ほかの問題(呼吸、離床)の原因にもなるので、上位に置く理由を説明できるようにする
  4. 生活に戻る食事の摂り方、栄養、退院後の生活への不安

問い:今日の受け持ちの方で、一番早く手を打たないと危ないのはどれ?その根拠になる観察結果は?

STEP 4

看護計画を考える観点

例として「無気肺・肺炎のリスク」。ほかの看護問題も、同じ3つの枠で考える。

観察(OP) 何を、いつ、どの頻度で見る?

  • 呼吸数・SpO2・呼吸音・痰の性状を、どのタイミングで測るか
  • どんな変化があったら、すぐに報告するか(数値の目安を自分で調べて決める)

ケア(TP) 看護師として何をする?

  • 深呼吸と咳を、痛みを抑えながら行える工夫(創部を押さえる、鎮痛薬を使うタイミング)
  • 早期の離床と、体の向きを変えることの支援

指導(EP) 本人に何を伝え、何をできるようにする?

  • なぜ深呼吸と離床が大切なのかを、本人がわかる言葉で
  • 痛いときに我慢せず伝えてよいこと

問い:この計画は、受け持ちの方の年齢、理解の程度、痛みの強さに合っている?「誰が見ても同じ計画」になっていない?
